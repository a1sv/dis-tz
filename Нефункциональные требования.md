## 1. Требования к производительности

### 1.1 Время отклика API

| Тип запроса | P50 | P95   | P99    | Максимум |
|-------------|-----|-------|--------|----------|
| Чтение (GET) | 100ms | 300ms | 400ms  | 500ms    |
| Запись (POST/PUT) | 200ms | 500ms | 800ms  | 1000ms   |
| Поиск/фильтрация | 200ms | 500ms | 8000ms | 1000ms   |

### 1.2 Пропускная способность

| Параметр | Значение |
|----------|----------|
| Максимальное количество одновременных пользователей | 500      |
| Активные сессии | 2000     |
| Запросов в секунду (RPS) | 100      |
| Запросов в секунду в пиковые часы | 1000     |

### 1.3 Время загрузки интерфейса

| Метрика | Значение |
|---------|----------|
| Первая отрисовка (FCP) | < 1.5с   |
| Время до взаимодействия (TTI) | < 3с     |
| Загрузка страницы со списком заявок | < 2с     |
| Загрузка детальной карточки заявки | < 1с     |

## 2. Требования к безопасности

### 2.1 Аутентификация и авторизация

| Требование | Реализация |
|------------|------------|
| Хранение паролей | Только хеш (bcrypt, cost factor ≥ 10) |
| Длина пароля | Минимум 8 символов |
| Сложность пароля | Заглавные, строчные, цифры, спецсимволы |
| Время жизни сессии | JWT — 1 час; refresh token — 30 дней |
| Блокировка после неудачных попыток | 5 попыток → блок 15 минут |

### 2.2 Защита от атак

| Тип атаки | Механизм защиты |
|-----------|-----------------|
| SQL Injection | ORM/параметризованные запросы |
| XSS | Экранирование вывода, CSP заголовки |
| CSRF | CSRF-токены для форм |
| Brute Force | Rate limiting, CAPTCHA после 3 попыток |
| MITM | Только HTTPS (TLS 1.2+) |

### 2.3 Контроль доступа

| Роль              | Доступ к данным | Действия |
|-------------------|-----------------|----------|
| **Администратор** | Все данные | CRUD пользователей, все операции |
| **Менеджер**      | Все заявки | Создание, назначение, проверка завершения |
| **Наладчик**      | Свои и новые заявки | Выполнение, комментарии, изменение статуса |

### 2.4 Аудит и логирование безопасности

| Событие | Обязательность логирования |
|---------|---------------------------|
| Вход в систему | ✅ (кто, когда, с какого IP) |
| Изменение пароля | ✅ |
| Изменение прав доступа | ✅ |
| Удаление заявки/комментария | ✅ |
| Экспорт данных | ✅ |
| Неудачные попытки входа | ✅ (с IP) |

### 2.5 Хранение данных

| Тип данных | Шифрование | Хранение  |
|------------|------------|-----------|
| Пароли | bcrypt | Бессрочно |
| Персональные данные (ФИО, телефон) | Шифрование на уровне БД (AES-256) |           |
| Логи доступа | Без шифрования | 1 год     |
| Логи действий | Без шифрования | 1 год     |
| Удаленные заявки | Мягкое удаление | 6 месяцев |

## 3. Масштабируемость

### 3.1 Горизонтальное масштабирование

| Компонент | Стратегия | Максимум нод         |
|-----------|-----------|----------------------|
| Backend API (бизнес-логика) | Stateless, за балансировщиком | 2                    |
| База данных | Master-Replica (Read Replica для отчетов) | 1 master + 2 replica |
| Очереди | RabbitMQ Cluster | 1 нода               |

### 3.2 Вертикальное масштабирование

| Компонент | Minimal          | Recommended      | Maximum            |
|-----------|------------------|------------------|--------------------|
| API сервер | 2 vCPU / 2GB RAM | 4 vCPU / 4GB RAM | 16 vCPU / 16GB RAM |
| PostgreSQL | 2 vCPU / 4GB RAM | 4 vCPU / 8GB RAM | 16 vCPU / 16GB RAM |

## 4. Требования к логированию и мониторингу
### 4.1 Метрики для мониторинга

| Категория | Метрика | Порог срабатывания |
|-----------|---------|--------------------|
| **Системные** | CPU загрузка | > 80%              |
| | Память | > 85%              |
| | Дисковое пространство | < 20% свободно     |
| **Прикладные** | Время отклика API | > 1s (p95)         |
| | Ошибки API | > 3% запросов      |
| | HTTP 5xx | > 50 в минуту      |
| | Количество активных заявок | > 1000             |
| **Бизнес** | Просроченные заявки | > 10               |
| | Новые заявки без назначения | ожидают > 1 часа   |

### 4.2 Инструменты (предлагаемые)

| Назначение | Инструмент |
|------------|------------|
| Сбор логов | ELK Stack (Elasticsearch + Logstash + Kibana) или Loki + Grafana |
| Метрики | Prometheus + Grafana |
| Трейсинг | Jaeger (для микросервисов) |
| Alerting | Alertmanager (Email) |
