#### Общие требования к API контрактам
- Версионированное API
- Проверка аутентификации
- Проверка авторизации
- Валидация запросов
- Rate limit
- Проверка ключей индемпотентности
- Документирование методов

#### Методы
 - CRUD операции для сущности пользователя (регистрация, смена пароля, получение пользволя по ID и список пользователей)
 - Создание роли
 - Назначение роли пользователю
 - CRUD операции для сущности организации, GetAll с параметрами для пагинации, фильтрации и сортировки
 - CRUD операции для сущности инструмента и его и видов, GetAll с параметрами для пагинации, фильтрации и сортировки
 - CRUD операции для сущности Изделие → Техпроцесс → Операция, GetAll с параметрами для пагинации, фильтрации и сортировки
 - CRUD операции для сущности станков и линий
 - CRUD операции для сущности проект
 - CRUD операции для сущности цех -> участок -> линия -> станок
 - Прикрепление и открепление пользователя к организации
 - Прикрепление и открепление проекта к организации
 - Прикрепление и открепление пользователя к "Станку и Операции"
 - Прикрепление и открепление цех -> участок -> линия -> станок к проекту
 - Полнотекстовый поиск по организациям, пользователям, инструменту и его характеристикам с параметрами
 - Журнал изменений и активности пользователя в "Изделие → Техпроцесс → Операция" внутри Проекта
 - Методы для использования адаптера интеграции с 1С (смотреть интеграцию с 1С)
 - Методы для сохранения файлов (локально и в s3)
