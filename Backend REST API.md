#### Общие требования к API контрактам
- Версионированное API
- Проверка аутентификации
- Проверка авторизации
- Валидация запросов
- Rate limit
- Проверка ключей индемпотентности
- Документирование методов

#### Методы
 - CRUD операции для сущности пользователя (регистрация, смена пароля, получение пользволя по ID и список пользователей)
 - Создание роли
 - Назначение роли пользователю
 - CRUD операции для сущности организации
 - CRUD операции для сушности инструмента и его и видов
 - CRUD операции для сушности Изделие → Техпроцесс → Операция
 - CRUD операции для сушности станков и линий
 - Прикрепление и открепление пользователя к организации
 - Прикрепление и открепление пользователя к "Станку и Операции"
 - Журнал изменений и активности пользователя в "Изделие → Техпроцесс → Операция"
 - Методы для использования адаптера интеграции с 1С (смотреть интеграцию с 1С)
 - Методы для сохранения файлов (локально или в s3)
