#### API ДЛЯ ОБМЕНА С 1С (Требуется реализовать методы на стороне 1С и адаптеры их использования на стороне бэкенда приложения)
1. Получение номенклатуры
2. Получение остатков на складе заказчика
3. Получение поступлений (накладные на перемещение)
4. Отправка актов на списание (пачкой)
5. Отправка требования-накладной (выдача наладчику) —
   опционально
6. Отправка заказа поставщику (сигнал «пора заказывать»)

- Методы должны проверять жизнеспособность хоста 1С и использовать механизм переотправки (retry)
