## Краткое содержание по разделам

### Раздел 1: Вводная информация

**Общая концепция приложения.md** включает:
- Первичное описание бизнес-логики
- Основные сценарии использования
- Цели создания системы

### Раздел 2: Техническая спецификация

**Технологический стэк.md** (требует исправления формулировок):
- Перечень предполагаемых технологий
- Требования к бэкенду и фронтенду

**Модели данных процесса.md**:
- Описание сущностей предметной области
- Связи между данными
- Атрибуты процессов

**Backend REST API.md** (последний коммит 30.05.2026):
- Список эндпоинтов
- Методы HTTP
- Форматы запросов/ответов

### Раздел 3: UI/UX

**Функциональность по экранам в UI.md**:
- Описание экранов web-версии
- Описание мобильного интерфейса
- Навигация между экранами

### Раздел 4: Интеграция

**Интеграция с 1С.md**:
- Точки интеграции
- Форматы обмена данными
- Сценарии синхронизации
